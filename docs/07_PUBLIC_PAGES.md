# Public Frontend Page Specifications

## Homepage

### Hero
Content from CMS.
Recommended concept:
"Building software, automations, campaigns, and creative systems that help businesses grow."

Do not hard-code this exact copy as final unless selected by owner.

Hero includes:
- professional title
- concise positioning
- primary CTA
- secondary CTA
- subtle animated visual
- optional availability indicator

### Expertise Strip
Quick proof of cross-functional capability:
Development / Automation / Advertising / Creative

### Services
Four initial service cards.
Each card:
- title
- concise outcome-focused summary
- selected capabilities
- detail link

### Selected Work
Feature 3-6 projects.
Mix disciplines to demonstrate breadth.

### Featured Advertising Case Study
Lead with a measurable result, then campaign context.

### Process
Recommended:
1. Understand
2. Architect
3. Execute
4. Optimize

### Tools / Stack
Display technologies/platforms by category rather than a logo wall with no context.

### Testimonials
Only render when published testimonials exist.

### Final CTA
Strong conversion section.

## Services Index
Hero + service grid + cross-disciplinary positioning + CTA.

## Service Detail
Every service page must feel custom through its content while sharing a reusable template.

Dynamic blocks:
- hero
- outcomes/problems solved
- capabilities
- process
- tools
- relevant projects
- relevant case studies
- FAQ
- CTA

## Work Index
Filters should update without full page reload when practical.
URL query parameters are preferred for shareable filters.

Project cards should emphasize visual work and role.

## Project Detail
Use editorial case-study storytelling.
Support:
- wide screenshots
- device/browser frames only when tasteful
- video
- gallery
- technical stack
- outcomes

## Case Study Index
Result-led cards.
Do not present misleading metrics without context.

## Case Study Detail
Metrics need labels/context.
Example:
"5.2x ROAS"
not simply "5.2x".

Show date range/platform/objective when available.

## Contact
Contact hero.
Inquiry form.
Direct email/social links.
Optional booking URL if configured.

## Footer
- identity
- short positioning
- nav
- social links
- contact
- copyright
