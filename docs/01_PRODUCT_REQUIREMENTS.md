# Product Requirements

## 1. Product
A personal professional portfolio that also functions as a lead-generation website.

The portfolio represents three core professional identities:
- Full-Stack Software Developer
- AI Automation Specialist
- Full-Stack Creative Digital Marketing & Advertising Expert

Creative production is also offered as a supporting/full service.

## 2. Primary Goals
1. Establish professional credibility.
2. Showcase multidisciplinary work without making the positioning confusing.
3. Convert visitors into qualified inquiries.
4. Present measurable advertising results.
5. Make content maintenance possible through an admin dashboard.
6. Make the website itself demonstrate strong frontend/software capability.

## 3. Target Audiences
- SME/business owners
- startup founders
- e-commerce brands
- agencies needing a technical/creative partner
- clinics, property businesses, service businesses, and other organizations needing internal systems
- prospective employers/partners
- companies needing automation
- companies needing Meta/TikTok advertising

## 4. Positioning
Primary concept:
"One partner across software, automation, growth, and creative execution."

Do not make the visitor decode a long list of unrelated skills. Present the disciplines as a connected system:
Build -> Automate -> Grow -> Create.

## 6. Public Pages

### Home
Sections:
1. Hero
2. Credibility / expertise strip
3. Services overview
4. Selected work
5. Featured advertising case study
6. Process / how I work
7. Skills/technology/platforms
8. Testimonials
9. Final CTA
10. Footer

### Services
Service directory plus individual service pages.

### My Work
Filterable portfolio covering:
- Software
- AI Automation
- Marketing
- Creative
- Web/e-commerce
- Other future categories

### Advertising Case Studies
Separate from general work because these require performance metrics and campaign context.

### Contact
Direct contact information + inquiry form + social/professional links.

### About
Recommended even if not in the main navigation initially. Useful for biography, experience, stack, and professional story.

## 7. CMS Requirements
Admin can:
- create/edit/archive/publish services
- create/edit/archive/publish projects
- create/edit/archive/publish case studies
- feature/unfeature content
- reorder featured content
- manage homepage copy
- toggle homepage sections
- manage bio/profile
- upload/manage media
- manage testimonials
- manage contact information
- manage social links
- manage SEO
- review contact inquiries

## 8. Publishing Model
Each major content type supports:
- draft
- published
- archived

Only published records are publicly visible.

## 9. Content Relationships
Projects can reference one or more services.
Case studies can reference one or more services.
Projects can have multiple categories/tags/technologies.
Case studies can have multiple platforms and metrics.

## 10. Conversion Strategy
Primary CTA:
- Start a Project / Let's Work Together

Secondary CTA:
- View My Work

Contextual CTAs:
- Discuss a Software Project
- Automate My Workflow
- Improve My Advertising
- Build Creative That Converts

CTA copy should be editable in admin.
